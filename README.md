
# Enterprise Commerce Platform

Plataforma empresarial para gestión de:

- pedidos
- inventario
- pagos
- clientes

Arquitectura:

Monolito modular preparado para evolucionar a microservicios.

Tecnologías principales:

- Java 21
- Spring Boot 3
- Gradle multi-module
- PostgreSQL
- RabbitMQ
- Docker
- Jenkins
- SonarQube
